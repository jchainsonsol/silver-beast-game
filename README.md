# Silver Beast

A browser-based action platformer inspired by classic 16-bit arcade brawlers.

## Story

Battle through a cyberpunk Solana city as the Silver Bull.

Defeat scammers.

Collect SOL.

Eat pizza to restore health.

Transform into increasingly powerful forms until you become the Armored Silver Bull and defeat the Rug Pull King.

## Controls

Arrow Keys / D-Pad - Move

A - Punch

S - Kick

D - Jump

Enter - Start
